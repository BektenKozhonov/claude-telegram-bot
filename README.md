# Claude Code Telegram — управление с телефона

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)

Telegram-бот, который даёт удалённый доступ к [Claude Code](https://claude.ai/code) на вашем компьютере.
Пишете боту с телефона — он запускает Claude Code в нужной папке, показывает ход работы как в терминале
и спрашивает разрешения кнопками. Переписка сохраняется в тех же сессиях, что и у локального `claude`,
поэтому `claude --resume` на компьютере продолжает диалог из Telegram.

Форк [claude-code-telegram](https://github.com/RichardAtCT/claude-code-telegram) (MIT) с доработками под Windows
и с удобством, знакомым по [opencode-telegram-bot](https://www.npmjs.com/package/@grinev/opencode-telegram-bot).
Оригинальный README: [docs/README.upstream.md](docs/README.upstream.md).

## Что умеет

**Ход работы как в терминале** — отдельные сообщения по мере работы Claude:
рассуждения, вызовы инструментов, дифф правок (`- старое` / `+ новое`), команды Bash и их вывод, ошибки.
Созданные файлы в конце приходят документами (читаются прямо из папки проекта, копий не создаётся;
секретные файлы вроде `.env` и ключей не отправляются).

**Разрешения кнопками** — перед записью файла или запуском команды приходит запрос
«✅ Один раз / 🔓 Всегда / ❌ Отклонить». Без ответа запрос отклоняется через 10 минут.

**Режимы** (кнопка на нижней клавиатуре): 🛠 Обычный, 📋 План (только план, ничего не меняет), ✏️ Авто-правки.
Режим «обход разрешений» намеренно отсутствует.

**Выбор папки на любом диске** (кнопка «📁 Папка», `/repo`, `/cd`) — навигация по дискам D: и дальше
кнопками или прямым путём: `/repo E:\work`. Диск C: закрыт.

**Управление работой** — `/abort` останавливает задачу и очищает очередь; новые сообщения во время работы
встают в очередь (до 5).

**Сессии и модель** — `/sessions` (продолжить любую сессию папки, в том числе созданную локально),
`/model` и кнопка 🧠 на клавиатуре (Fable, Opus, Sonnet, Haiku), `/new`, `/status`.

**Настройки** (`/settings`): ход работы как в терминале, присылать созданные файлы, компактный вывод,
подпись под ответом, очередь, сброс списка «Всегда разрешённых».

## Установка (Windows)

Нужны: Python 3.11+, [Claude Code CLI](https://claude.ai/code) с выполненным входом, токен бота от
[@BotFather](https://t.me/botfather) и ваш числовой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)).

```powershell
git clone <адрес-этого-репозитория> claude-telegram-bot
cd claude-telegram-bot
uv venv --python 3.12 ..\venv            # или python -m venv
uv pip install -e . --python ..\venv\Scripts\python.exe
copy .env.example .env                   # затем заполните .env
```

Минимальный `.env`:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_BOT_USERNAME=имя_бота_без_@
APPROVED_DIRECTORY=D:\projects           # стартовая папка
ALLOWED_USERS=123456789                  # только ваш ID
USE_SDK=true
CLAUDE_CLI_PATH=C:\Users\<вы>\.local\bin\claude.exe
DISABLE_TOOL_VALIDATION=true             # проверка имён инструментов заменена запросами в Telegram
```

Запуск (из папки проекта): `..\venv\Scripts\claude-telegram-bot.exe`.
Для автозапуска создайте задачу Планировщика Windows «при входе в систему» с этой командой
и рабочей папкой проекта.

## Безопасность

- Доступ только пользователям из `ALLOWED_USERS`. Для каждого токена должен работать **один** экземпляр бота
  (иначе ошибка `409 Conflict`).
- Claude работает на вашем компьютере с вашими правами. Файлы доступны на дисках D: и дальше; диск C:
  (профиль пользователя, токены, настройки Claude) закрыт проверками бота. Это проверки уровня бота,
  а не изоляция операционной системы: команда Bash может выйти за эти рамки, поэтому читайте запросы разрешений.
- «🔓 Всегда» разрешает инструмент целиком (например, `Bash`) навсегда; сбросить можно в `/settings`.
- Не публикуйте `.env` и токен бота; при утечке перевыпустите токен в @BotFather (`/revoke`).
- Репозиторий лучше держать приватным.
- Не пишите в одну сессию одновременно из Telegram и из локального `claude`.

## Структура доработок

| Файл | Что делает |
|------|------------|
| `src/bot/orchestrator.py` | команды, клавиатура, режимы, разрешения, `/abort`, очередь, `/settings`, браузер папок |
| `src/bot/live_feed.py` | лента хода работы и отправка созданных файлов |
| `src/claude/runtime.py` | настройки в `data/settings.json`, состояние запросов и активных сессий |
| `src/claude/sdk_integration.py` | режим доступа, `can_use_tool`, рассуждения и результаты инструментов |
| `src/security/roots.py` | граница доступа по дискам (D: и дальше) |
